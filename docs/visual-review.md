# 两本书 · 62章逐章配图审阅记录

> 本记录按读者首次学习的路径，逐章检查正文中的结构、概念、时间线、逻辑关系、理解/表达练习及已有插图。它记录的是**编辑判断与实际 GitHub 文件修改**，不是已开展正式用户阅读实验或全面人工视觉无障碍审计的声明。

## 审图标准

1. **有助于少读错一次**：结构层级、修饰归属、逻辑方向或词义差异，用视觉比连续文字更容易区分。
2. **图紧靠讲解**：在包含相关例句或分析的章节内嵌，不把解释图堆到书末。
3. **减少装饰**：单个简单句、已经有清楚表格或代码示意的部分，不强行配图。
4. **适合反复查看**：图中使用短例句与简短标记，附有图片替代文字，均采用本地 SVG，可无损放大。
5. **保持前后分工**：第一本以句法、从句和逻辑为主；第二本以意义网络、场景输出与迁移训练为主。

## 实际调整汇总

- 原有教学图片保持可用，**本次新建 38 幅独立 SVG**。
- 其中 37 幅用于原先没有图的章节；另 1 幅专门替换第二本第31章与第30章重复的图，避免相邻章节内容雷同。
- 两本书合计 **62 章，其中 50 章配有至少一幅图**；另 12 章有意保留文字、表格或代码流程，不以配图数量为目标。
- 新图均保留在 `docs/public/images/`，正文引用通过根相对路径 `/images/...` 由 VitePress 处理。

这批图应该用真实阅读行为检验：读者是否更快找到主干、能否避免读反因果和否定、能否借图完成新场景中的英语表达。如果一张图重复文字、标注太密或缩到移动端看不清，应优先**删改或简化它**，而非为达成每章有图的指标盲目保留。
