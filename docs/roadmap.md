# 英语能力进阶 · 两书学习路线

英语阅读和英语表达可以相互促进，但这两本书分工不同：**结构解构负责解决看不懂，直接联结负责解决只会翻译、不易主动表达。**

## 起步阶段：先掌握读句子的基本方法

阅读 [第一本第1—12章](/books/reading/)，能够识别五大句型和基本谓语结构。每学完一章，做随堂练习；之后进入 [48道额外训练](/books/reading/appendix/training-path)。

## 中段：短语与从句的层级

继续第一本第13—27章。只有真正看懂一段英文时，后续的“直接理解”训练才有可靠的语义基础。

## 迁移阶段：直接从场景唤起英文

打开 [第二本《英语思维》](/books/thinking/)，让熟悉句型和表达与实际情境建立联系；读到困难句可以随时回第一本查结构。

## 最终阶段：用英语解释真实问题

最后要能做到：理解英文资料、组织自己的观点、与他人沟通。中文可以作为补充工具，但你能够在熟悉场景下独立完成越来越多的英语理解与表达任务。
