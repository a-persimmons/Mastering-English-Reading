# 英语句子结构速查表

## 五大基本句型

| 句型 | 识别公式 | 例子 | 切入问题 |
| --- | --- | --- | --- |
| SV | 主语 + 谓语 | Birds fly. | 谁做了什么？ |
| SVC | 主语 + 系动词 + 表语 | She feels tired. | 主语怎么样？ |
| SVO | 主语 + 谓语 + 宾语 | I like music. | 谓语直接支配什么？ |
| SVOO | 主语 + 谓语 + 双宾语 | He gave me a pen. | 给谁什么？ |
| SVOC | 主语 + 谓语 + 宾语 + 补语 | We found it useful. | 宾语处于什么状态？ |

## 连接词与关系词

| 看到 | 先想到 | 但须排除 |
| --- | --- | --- |
| who / which / whose | 关系从句可能修饰前面的名词 | 疑问用法、其他非定语用途 |
| that | 宾语从句、定语从句、同位语从句等 | that book 是限定词 + 名词 |
| when / while / before | 时间关系 | when 也可能是定语/名词性从句成分 |
| because / since | 原因 | since 也可能表示“自从” |
| if / unless | 条件 | if 在宾语从句中也可表达“是否” |
| although / even though | 让步 | 不能把它们理解成因果 |
| so that / so...that | 目的、结果 | 两种结构与语义不同 |
| and / but / or | 并列或转折 | 连接的未必是完整分句 |

## 三类动词形式

| 线索 | 可能功能 | 阅读动作 |
| --- | --- | --- |
| is / have / will + 相关动词形式 | 谓语组 | 整体读时间、体、语态、情态 |
| to do | 不定式 | 看作宾语、目的、补语、定语等 |
| doing / done | 动名词、分词、进行/被动谓语的组成部分 | 必须连同上下文确定 |
