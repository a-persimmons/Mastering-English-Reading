## 两本书，是一条连续的成长路线

| | 第一本 · 英语句子解构 | 第二本 · 英语思维 |
| --- | --- | --- |
| 要解决的问题 | 每个单词都认识，却不理解整句 | 知道句意，却依赖逐词翻译 |
| 核心训练 | 找主干、识别短语与从句、读逻辑 | 情境理解、概念联结、表达迁移 |
| 阅读方式 | 结构示范 → 独立拆句 → 答案复盘 | 情境 → 英文输入 → 主动生成 → 延迟复测 |
| 当前状态 | 完整30章及48道附加题 | 32章正文第一版已完成，进入审稿和精修 |

### 先学哪本？

初高中词汇基础、阅读时常卡在句子结构的人，建议先从 [第一本第1章](/books/reading/chapters/01) 开始；读懂了以后，再用 [第二本第1章](/books/thinking/chapters/01) 练习摆脱逐词翻译。两本书可以交替学习，不需要第一本学到百分之百才开始第二本。
