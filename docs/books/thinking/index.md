# 第二本｜英语思维

**从中文翻译到英语直觉：让英语直接连接概念、情境与表达。**

## 这本书解决什么问题？

第一本解决“我认识每个词，为什么读不懂整句”；第二本进一步解决“我能分析句子，却总要先翻成中文，自己表达时也要先在心里写中文”。

这不是所谓“抛弃中文”的训练。母语可以帮助学习，而目标是通过足够丰富的英语输入和主动回忆，让熟悉的概念与英文表达渐渐建立更直接的联系。

## 学习方法

1. 从**情境**开始，而不是先记中文释义；
2. 通过英语句子和词块建立概念联系；
3. 在**新情境**里主动调用表达；
4. 区分“能认出来”与“不看答案就能说出来”；
5. 根据反馈复练，而不是只增加新知识。
