# 第二本阅读指南：练的是加工过程，不是背知识点

## 先明确目标

所谓“英语思维”，在本书中特指：在熟悉的情境中，较少依赖逐词中文翻译，能够**直接理解英文所表达的概念，并逐步主动组织英文表达**。它不是神秘的脑内模式，不等于必须像所谓英语母语者那样想问题。

## 每章的四次训练

1. **情境觉察**：先看事实或场景，不急着翻译。
2. **英语输入**：接触词块、常用表达及对比句，解释它为什么在该场景自然。
3. **迁移输出**：换人物、时间、目的，自己说出新的英文。
4. **延迟复测**：隔一天或一周，在不给中文标准译文的情况下，再从情境唤起表达。

允许初学时使用中文解释，但逐渐缩短“中文词对词替换”的路径。

## 怎样配合第一本？

- 完全看不懂句子结构：打开 [第一本拆句六步法](/books/reading/method)。
- 已经读懂，但表达时只能回译：回到本书做跨情境复述和主动回忆。
- 遇生词：先借助上下文推测词义范围，不能确定时再查词，不把“猜不中”视作失败。

## 如何判定自己有进步？

相同难度的日常场景下，观察你是否能够：(1) 不参考翻译提取正确意义；(2) 用英语独立表达核心事实；(3) 换一个场景仍可使用；(4) 复练一周后仍能完成。速度只是辅助指标，准确性优先。
