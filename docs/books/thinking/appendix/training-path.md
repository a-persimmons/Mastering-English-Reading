## 如何评分

每题可从三个维度各记0—2分：**意义与事实准确性**、**英语表达或推断依据**、**换场景的迁移能力**。总分不是语言水平证书。请先独立作答，隔天或一周之后换情境再测，比较同类错误有没有减少。

::: tip 关于“英语思维”

不能以“全程不想中文”作为唯一通过标准。读对事实、表达得体、遇到不确定主动查证，是更可操作的目标。
:::
