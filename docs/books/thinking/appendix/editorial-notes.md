# 《英语思维》三轮编辑审查记录

> 本记录对应《英语思维：从中文翻译到英语直觉》第一版全稿。以下是本次已执行的**内部内容审校与修改**，不是第三方编辑认证，也不等于已经用真实学习者试验验证效果。

## 编辑前提：第二本不能只是第一本改名

第一本训练的是识别句法、主干、从句和长难句；第二本训练的是**概念联结、情境选择、自动提取、跨场景迁移**。这两种能力可相互支持，但教学任务不能完全重叠。

全书分七篇，32章依次承担：

| 篇 | 主要训练责任 | 避免重复的边界 |
| --- | --- | --- |
| 1（1—4） | 定义目标、解释母语中介、建立可练的循环 | 不把禁用中文当目标 |
| 2（5—9） | 名词概念、动词事件、词块、空间、抽象词义 | 不代替第一本的词性系统课 |
| 3（10—14） | 叙述视角、事件先后、信息推进、证据逻辑 | 区分结构分析与表达选择 |
| 4（15—19） | 状态、情绪、计划、请求、语气 | 围绕交际意图，而非孤立句型表 |
| 5（20—24） | 阅读与听力输入、推断、段落和言外之意 | 听力与阅读不能互相代替 |
| 6（25—29） | 看画面说英语、即时答复、自述、绕述、叙事 | 从识别转成主动提取 |
| 7（30—32） | 比较取舍、工作应用、长期训练系统 | 不让宏大理念替代行动检验 |

## 第一轮 · 去重复与章节职责

**审查内容**：回看全部32章的题目与教学重点，检查相邻章节的职责、先后依赖、是否把相似词块反复当成“新知识”。

**已修改**：
- 第6章补充清楚的“迁移练习”入口，保证学习环节可找到。
- 第22章明确其与第一本第28章的区别：从“如何在句中推词义”转为“连续阅读时何时忽略、推测、查证”。
- 第23章明确与第13章的区别：第13章是**安排话题与已知/新信息**，第23章是**段落整体主旨、指代与作者的结论边界**。
- 第27章明确与第4章的区别：第4章提供单个表达的五步训练，第27章训练让英语出现在日常内部语言中。
- 第32章将部分过于熟悉的“钥匙落家里、时间快耗尽”直接复现题换为新的“耳机、出租车、燃料”等场景，检验迁移而非纯记忆。

**保留的有价值复现**：类似 `run out of`、`leave`、情态与否定范围在不同阶段出现，是为了检验“初学能懂 → 新场景能用 → 不看答案能反应”，不是让同一页讲解原封不动重复。

## 第二轮 · 学习目标与语言准确性

**审查重点**：
1. 每章能否从具体场景出发，把英语表达与意义建立联系。
2. 是否区分英语**结构的形式**、交际意图、语境推断，以及已知事实。
3. 是否在中文母语学习者常见错配处提供对比，例如 `borrow/lend`、`get` 的多种事件、`interested/interesting`、`not all`。
4. 是否允许必要的中文辅助，而非提出“完全不想中文”的无法可靠检验要求。
5. 答案能否解释为什么选这种表达，以及哪些场景里不能强行套模板。

**实质补充**：新增 [48道分级迁移练习](/books/thinking/appendix/training-path)，分四组各12道，要求在陌生但熟悉生活经验的情境下完成独立回答。每题均附参考表达与判断依据。覆盖：
- 情境到词块与事件；
- 事件时间与表达意图；
- 连续阅读中的指代、推理与证据强度；
- 工作和生活中的回答、复述、讨论与澄清。

**仍需注意的边界**：这套训练不等于语言习得实验，也未通过人工语音评分证明口语流利度。第21章明确需要配合真实音频进行听觉训练，静态网页不能代替声音输入。

## 第三轮 · 中文文风、版式与图解

**本轮处理**：
- 统一“观察到的事实／可能的解释／建议行动”的表达边界；避免把文化差异、隐喻、英语思维包装成放之四海而皆准的规则。
- 每章维持“具体情境 → 解释 → 对比 → 主动练习 → 隐藏答案 → 复训”的可读形式。
- 保留书内必要中文解释，但练习强调独立输出与延迟复测；删除“只要不翻译就一定学会”类暗示。
- 补入简洁本地 SVG 结构图：英文—概念—情境、介词空间路线、段落话题推进、输入理解流程、言外之意三层、观察—假设—行动。
- 增设练习路线和速查卡，利用 VitePress 原生折叠答案区，不添加依赖外部图片服务的素材。

**没有做的事**：未进行真实读者 A/B 测试、全书外籍语言教师逐句审校、音频母语发音校验。后续若有读者错题和表达录音，可据此进行第二版的例句替换、难度重排和口语练习升级。

## 验收范围

仓库自动检查脚本将验证：**第二本32章存在且题目完整、练习与答案块存在、四组48道迁移题完整、站内链接及图片可解析**；VitePress 构建、GitHub Pages 发布结果另以最新 GitHub Actions 记录为准。

**编辑判断**：第一版具备连续自学教材的基本结构；其是否真正帮助个人养成更熟练的英语直接理解与表达，还应通过长期复训结果来检验。
