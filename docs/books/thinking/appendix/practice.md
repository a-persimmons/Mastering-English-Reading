# 《英语思维》主动练习与错题记录

学完一章以后，真正关键的不是“这章我看完了”，而是能否在不给原句的情况下从情境中调用英语。

## 你只需要记录六个字段

```text
日期：
场景（不写完整中文待翻译句）：
第一次独立回答：
参考句/听到的真实表达：
错误归类（不懂意义 / 词块不熟 / 逻辑错 / 忘词 / 不得体）：
隔天复测 + 换情境结果：
```

## 每周固定一次复盘

抽取上周最常错的三种情境。分别用**另一人物、地点或时间**重做；如果上一题是“落下钥匙”，这次就换成“落下工作证”或“忘带充电器”。

**不要只复述上周标准答案。** 难度应与目前基础匹配，目标是准确和可迁移。

## 什么时候回到第一本？

如果不能确定 `not all` 的范围、关系从句修饰谁，或者时态改变了事件顺序，先用 [第一本的拆句六步法](/books/reading/method) 修正理解，再返回这里练习快速调用。
