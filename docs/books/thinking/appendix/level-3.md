# 训练 C · 无翻译阅读与语境推断

> **对应第20—24章**。读出含义、论证关系和不确定性；不要只完成字面翻译。

## 作答规则

第一次先遮住解析，写下你自己的英文或解释。第二次只看场景，尝试在三到五秒内开始回答；如果超过这个时间也不必慌，**准确理解和表达优先于速度**。第三次换一个新的情境复测。参考答案不是唯一正确形式。

## 01 · 情境任务

The library closes at six, but it is still open now. 两个时间信息是什么？

::: details 查看参考表达与判断依据

**参考**：图书馆六点关门，目前还开着。

**为什么**：closes at six 是日常安排；still open 指当前状态。

::: 

## 02 · 情境任务

Nora ordered a replacement charger because hers stopped working. 她为什么下单？

::: details 查看参考表达与判断依据

**参考**：Because her charger stopped working.

**为什么**：hers 回指她的充电器；because 给出原因。

::: 

## 03 · 情境任务

The street was deserted; no cars or people were visible. 猜 deserted。

::: details 查看参考表达与判断依据

**参考**：empty of people and traffic / 空无一人（车）。

**为什么**：分号后的解释提供直接证据。

::: 

## 04 · 情境任务

The cup was fragile, so it broke when it fell. 猜 fragile。

::: details 查看参考表达与判断依据

**参考**：easy to break / 易碎的。

**为什么**：原因与后果共同约束词义，非随机猜测。

::: 

## 05 · 情境任务

The project may be delayed. 能确定一定延期吗？

::: details 查看参考表达与判断依据

**参考**：不能，may 表示可能延期。

**为什么**：不要把不确定判断翻成确定事实。

::: 

## 06 · 情境任务

Not all reviewers agreed. 能说“没有一人同意”吗？

::: details 查看参考表达与判断依据

**为什么**：Not all 是部分否定。

## 07 · 情境任务

Mia opened the window. It made the room cooler. It 最可能回指什么？

::: details 查看参考表达与判断依据

**参考**：前句开窗这件事，而非必须是 window 这个名词。

**为什么**：跨句代词可能回指事件；要看句意。

::: 

## 08 · 情境任务

He was reluctant to answer and remained silent. 猜 reluctant。

::: details 查看参考表达与判断依据

**参考**：unwilling / 不情愿的，较可能。

**为什么**：remain silent 支持，但也可有其他原因，保留一定不确定性。

::: 

## 09 · 情境任务

The report claims the treatment works, but no data are shown. 应如何判断？

::: details 查看参考表达与判断依据

**参考**：报告作出了有效的主张，但文段未给出数据支持。

**为什么**：claims ≠ independently proves，不能确认疗效。

::: 

## 10 · 情境任务

A: Are you coming? B: I have another meeting. B 的潜在意图是什么？

::: details 查看参考表达与判断依据

**参考**：可能委婉表示无法参加，但不是显式拒绝。

**为什么**：交际推断需要语境，不能称百分之百。

::: 

## 11 · 情境任务

She found the instructions confusing, so she asked for help. 结果是什么？

::: details 查看参考表达与判断依据

**参考**：她因为说明难理解而寻求帮助。

**为什么**：confusing 描述说明书给人的感受，so 引出行动。

::: 

## 12 · 情境任务

The first test succeeded, but later tests failed. 能说测试均成功吗？

::: details 查看参考表达与判断依据

**参考**：不能。第一次成功，后续失败。

**为什么**：but 对比两组事实，结论不能只取前半段。

::: 

## 怎么复训

把本组做错的三题改成自己的真实情境，不要只背参考答案。隔天再做一次，再隔一周做一次。若答案不同，检查**事实、范围、时态、语气、搭配及是否编造信息**。
