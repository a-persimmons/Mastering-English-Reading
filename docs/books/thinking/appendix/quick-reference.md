# 《英语思维》随手速查卡

这页不是一本中英词典。它帮助你在真实情境里**先判断想表达哪种信息，再选择英语**。

## 1. 我现在要表达什么？

| 表达意图 | 起步句型 | 小心的错误 |
| --- | --- | --- |
| 引入某地存在的东西 | There is / There are ... | 不要把所有“有”变成 have |
| 说自己拥有某物 | I have ... | 有时 have 是症状或活动的搭配 |
| 描述状态变化 | get / become + 状态 | 不要把 get 全译成“得到” |
| 表达个人感受 | I feel ... / I'm ... | interested 与 interesting 有区别 |
| 说出正在考虑的计划 | I'm thinking about doing ... | 不等于已经决定 |
| 请求别人帮助 | Could you ...? | 意图和场景比句子长短重要 |
| 提出推测 | It may / might ... | 不要升级为肯定事实 |
| 引出事实与限制 | We observed ... but ... | 不要把推测写成结论 |

## 2. 四次观察，四种学习结果

1. **看到能懂**：还不能保证你主动会说。
2. **看场景能说**：初步建立了情境到表达的联系。
3. **换场景能说**：初步证明可以迁移。
4. **隔天能说**：更有助于判断知识能否保持。

## 3. 忘词时的英语绕述

- **It's a kind of ...** 它是一种……
- **You use it to ...** 用它做……
- **It looks like ...** 看起来像……
- **It's the thing that ...** 就是那个能够……的东西

忘了物品名称不等于沟通结束；事后仍要核对自然词汇。

## 4. 英文阅读的三遍法

1. 先抓人物、事实、问题、结果。
2. 对卡点再做词块、从句、上下文分析。
3. 不看逐词翻译，用两句简单英语复述。

## 5. 猜词与意译的边界

**语法线索 + 词块搭配 + 上下文重述 / 对比 / 因果 = 推断证据**。  
证据不够时可以保留问号；涉及否定、风险、金额、结论等关键信息应优先查证。

## 6. 十五分钟自测

选三个场景：一个日常动作、一个请求、一个需要表达不确定的观察。各回答一次，再给每个场景做一项变化。记录：哪句说不出来、为什么、何时复测。
