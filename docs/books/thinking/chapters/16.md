# 第16章 如何表达感觉、经历与情绪？

> **本章目标**：看到身体反应、情绪和经历时，先确定“我正经历什么”，再选择英语表达。你要区分**自己的感受**和**引起感受的事物**，以及暂时情绪和持续状态。

## 1. 同样是“高兴”，原因与感受有区别

![bored 和 boring 表达人的感受或事物特点](/images/thinking-feeling.svg)

**I'm excited about the trip.** 我对旅行很兴奋。  
**The trip sounds exciting.** 这次旅行听上去令人兴奋。

前句 excited 描述我的状态；后句 exciting 描述旅行给人的感觉。

另一个常见组合：
- **I'm bored.** 我觉得无聊。
- **This movie is boring.** 这部电影很无聊。

不要说 *I'm boring* 来表达“我感觉无聊”。这句话更可能是“我是个很无趣的人”，语义不同。

## 2. 从身体感受开始，练场景对应

你走了很远的路，腿酸、很渴，想坐下。

**I'm tired. I need some water. Can we sit down for a minute?**

一个场景可以含有三个意图：描述状态、表达需求、提出请求。不必先写长中文，再在脑中逐词翻译。

如果你只是短时间有点疲劳，还可说 **I'm a bit tired.**；如果累到精疲力尽，**I'm exhausted.** 比 tired 强得多。**强度也是意义的一部分。**

## 3. 情绪不是简单的单词替换

- **I'm worried about the interview.** 我担心面试。
- **I'm nervous before interviews.** 我在面试前容易紧张。
- **I'm disappointed with the result.** 我对结果失望。
- **I'm proud of my progress.** 我为自己的进步感到骄傲。

介词和搭配很重要：worried **about**，proud **of**，disappointed **with/by** 需结合宾语意义。

## 4. 感受、评价与事实不要混为一谈

**I felt ignored in the meeting.** 我在会议中感到被忽视。  
它陈述你的主观感受，不自动证明所有同事有意排斥你。

**No one responded when I asked a question.** 我提问时没人回应。  
后一句陈述可观察的事实。

在英语里描述真实经历时，分清“发生的事件”和“我对此的感受”，能够更准确沟通。

## 5. 讲述经历时，怎么说先后？

> I was nervous before my first presentation. But once I started speaking, I felt calmer. Afterward, I was relieved.

三个时间阶段：
1. 演讲前紧张；
2. 开始说话后逐渐平静；
3. 结束后如释重负。

**relieved** 不等于 happy，常表示压力、担心或负担解除后的轻松。描述过程比一次性说“我很高兴”包含更多真实信息。

## 6. 主动表达练习

A. 这部电影令人失望；我感到失望。分别说。  
B. 你因为明天的考试感到紧张。  
C. 朋友取得新工作，你为他开心。  
D. 你今天有点疲倦，想稍后再谈。

::: details 参考答案与依据

- **A.** **The movie was disappointing. I was disappointed.** 注意 -ing 与 -ed 的指向。
- **B.** **I'm nervous about tomorrow's exam.**
- **C.** **I'm happy for you.** / **I'm really glad you got the job.** 不需要把中文“替你”逐字变成一个介词结构。
- **D.** **I'm a little tired today. Could we talk later?** 状态和请求分别说更清楚。

:::

## 7. 一段无提示复述

请描述一件自己最近完成、起初有点担心的事。尝试用四句：
- 起初感受；
- 发生的事件；
- 感受如何变化；
- 最终结果。

如果你不知道某个情绪词，可以先用 `I felt good/bad/worried` 这类已有词表达，不必因为某个精确形容词不会而完全停住。

**过关标准**：能根据实际情绪、强度和发生顺序选择词句，而不只是凑出语法正确的情绪标签。
