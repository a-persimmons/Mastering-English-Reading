# 读前说明：这本书应该怎么用

这本书写给这样的读者：中文是母语，有初高中英语词汇基础，认识一些英语单词，但看到完整句子不知道怎样连起来理解。

## 你要解决的并不是一个问题

第一种困难是 **结构识别**：*The boy who lives next door gave me a book.* 哪一部分是主干？谁在修饰谁？

第二种困难是 **语义整合**：即使识别句型，也要读出否定、条件、对比、情态和代词指代。

第三种困难是 **词义推断**：阅读时遇到生词，先从句法位置、构词与上下文推测它的范围；关键处仍要查证。

第四种困难是 **意译**：保留所有重要信息，用中文自然表达，而不是按英语词序搬运。

| 篇 | 章节 | 你能增加的能力 |

| 第一篇 · 整体框架 | 01–04 | 认识短语、从句、主句；掌握拆句步骤 |
| 第二篇 · 基本句型 | 05–12 | 判断五大句型、时态/情态、被动和特殊句式 |

## 一章怎样学，才不会只是“看懂讲解”

1. **先遮住答案读示例**：说出自己第一反应是什么。
2. **学结构辨认**：先圈主干，再拆附加信息。不能理解的词先标问号。
3. **完成练习再开答案**：不要把“看参考译文觉得懂了”当成掌握。
4. **写出依据**：为什么属于定语从句？为什么这个词可能是“减少”而不是“增加”？
5. **延迟复习**：隔一天和隔一周再做错题，能独立拆对才算有效学习。

::: tip 关于单词
本书以常见词为主，必要时使用生词帮助训练猜测。语法结构能缩小可能词义范围，但它无法取代词汇学习和字典。
:::

## 学习成果怎么测

先进行 [无提示综合测试](/books/reading/chapters/30)，保存自己的第一次答案；学完整本书再做一次。比较时不要只看中文译文，而要看 **结构是否正确、语气是否遗漏、猜词有没有证据、意译有没有多加事实**。
