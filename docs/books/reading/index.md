# 第一本｜英语句子解构

**从简单句到长难句：把英文句子拆成真正能理解的关系。**

::: tip 全书已完成
本书共有 **6篇30章**，附带 **48 道额外分级练习** 和结构图、速查表及错题复盘模板。
:::

## 为什么要读这本书？

你可能认识英语句子里的大部分单词，却不知道这些词之间是什么关系，因而无法理解完整意思。问题通常不是单纯“不认识词”，而是缺少辨认句子主干、词块、修饰与从句层级的方法。
