# 全书编辑审查记录

> 教材：《英语句子解构：从简单句到长难句》；仓库：a-persimmons/Mastering-English-Reading。本记录描述已经执行的三轮修订和实际可核查的交付内容。审稿是内容质量控制，不代表学习成效已经由真实读者实验验证。

## 审稿原则

受众是中文母语、初高中英语词汇基础的个人读者。核心目标有四项：**在认识单词时能识别句法结构，在句法基础上整合逻辑和原意，遇到生词时有证据地推断，在理解准确后自然意译**。

英语阅读不是五大句型的机械翻译：语境、搭配、否定范围、指代与真实世界常识同样重要。面对结构或词义歧义，允许明确“不确定”，不能靠编造细节强行给出唯一答案。

## 第一轮 · 全书去重复与结构审核

**核查范围**：30 章标题、章节职责、基本句型到复杂句的先修关系、每章练习与答案区、示例句与译文。

**职责边界**：1—4 章建立概念与拆句流程；5—10 章讲结构骨架；11—12 章讲动词组所携带的时间、语气与语态；13—18 章讲短语和非谓语扩展；19—24 章讲分句连接与嵌套；25—27 章综合长难句；28—30 章猜词、意译和独立训练。

**修改情况**：

- 第 4 章将“粗读”和后续六步区分，避免步骤数含混。
- 第 8 章澄清双宾语与宾补的语义差别，去掉不自然的笼统解释。
- 第 13 章将容易误导的短语对比改成明确的分词修饰例句。
- 第 24 章修正一句存在结构问题的例句，换成合法的“延迟确认从句边界”范例。

保留必要的**递进复现**：主干在第一篇作为概念、第二篇作为定位技能、第五篇作为多层解构步骤再次出现。这种复现服务于训练，不以重复讲解充字数。

## 第二轮 · 学习目标、语法和迁移训练审核

**核查焦点**：能否只靠词义与结构建立命题理解；是否知道哪种连接词影响哪一层；能否区别直接所说、合理推断、未经证实的猜测；能否避免意译时引入原文没有的事实。

**实质补充**：新增 [48 题分级训练](/books/reading/appendix/training-path)，四组各 12 题，覆盖：五大句型、谓语和宾补；名词短语、介词短语和非谓语；定语/名词性/状语从句和逻辑范围；语境猜词、情态、不确定性与忠实意译。

每题提供**结构或证据解释、参考译文、易错点**；强调“参考译文不是唯一汉语表述，但命题不能改变”。章节中也保留原有随堂题，构成“讲解—练习—复盘—迁移”的路径。

**边界提醒**：词性和语境常只能帮助猜出词义范围，不能保证孤句猜词准确；涉及作者态度、否定、数据与关键结论的生词仍需查证。本书讲解了这一限制，避免把猜词技巧包装为万能方法。

## 构建与部署验收

- GitHub Actions 的首次 VitePress **Build site 步骤已经成功**，站点资源已生成并上传 Pages artifact。
- 首次 **Deploy to GitHub Pages 步骤失败（HTTP 404）**，日志明确提示仓库没有启用 GitHub Pages，并非构建失败。
- 需要仓库所有者打开 **Settings → Pages → Build and deployment → Source → GitHub Actions**，然后重新运行工作流。此动作需要仓库 Pages 管理权限，现有 GitHub 内容连接器不提供该设置写入操作。
- 启用之前，不能把预计站点地址宣称为已上线。

## 后续仍可加强的地方

这是一部以**句子解构为核心的自学教材第一版**，并不是按考试大纲穷尽英语语法的百科全书。下一步如果有真实读者错题数据，应优先扩充：定语从句边界易错题、歧义与语境猜词、段落级篇章理解，并按错题数据重新调整讲解篇幅。
