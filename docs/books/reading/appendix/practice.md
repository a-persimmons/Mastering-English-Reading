# 练习手册：怎样证明自己真的会拆句

## 不要把参考答案当作学习成果

每章末尾至少有一组练习。做题时**先写主句主干，再写修饰关系，最后写中文**。如果只看译文就觉得懂了，隔天换一题往往还是不会。

## 错题记录模板

```text
日期：
原句：
我的第一次理解：
最外层主干：
从句 / 非谓语 / 介词短语归属：
陌生词：候选意义 + 上下文证据 + 置信度
真正的错误环节：
最终中文：
一周后复测结果：
```

## 推荐复习间隔

初学时可在当天、隔天、7天后各做一次错题。间隔只是建议，核心是**不看原答案还能解释结构**。

## 何时查词

- 不影响核心命题：先跳过，读完整段后再回看。
- 能通过解释和对比明显推断：先写候选意义，再核查。
- 影响立场、否定、数值、专有名词或安全说明：马上核查，不要把猜测当确定。

## 自评

结构识别、关系与逻辑、猜词证据、中文表达准确性，每项记 0（做不到）、1（提示后做到）、2（独立做到）。**不是越快越好，而是理由能自圆其说且经得起原文核对。**
