# 第21章 目的、结果、让步与比较：别读反逻辑

> **本章任务**：学习读出说话人怎样把事件联系起来，尤其是“尽管……仍然……”和“为了……所以……”的区别。

## 1. 目的与结果不是一回事

**She spoke slowly so that everyone could understand.**

- 主句：She spoke slowly.
- so that 从句：everyone could understand.
- 此处解释“说得慢的目的”。

译：“她说得慢一些，好让每个人都能听懂。”

对照：**She spoke so slowly that everyone understood.**  
这里 **so + 副词 + that** 常描述程度带来的结果：“她说得很慢，以至于大家都听懂了。”

```text
so that + 分句       → 通常说明目的（有时可指结果，结合语境）
so + 形容词/副词 + that + 分句 → 程度及其结果
```

## 2. 让步表示“虽有阻力，事实仍成立”

**Although he was tired, he kept working.**

- although 从句：他很累（被承认的事实）。
- 主句：他仍然继续工作（与通常预期相反）。

注意标准英语里通常不把 *although... but...* 作为同一转折的成对连接词。汉语习惯“虽然……但是……”，英语一般是 *Although he was tired, he kept working.* 或 *He was tired, but he kept working.*

**Even if it rains, we'll go.** 即使下雨也去。*even if* 可引入假设；**even though it was raining** 常承认既有事实。

## 3. 不要把“结果”误当“目的”

**He was so busy that he forgot lunch.**

不是“为了忘记午饭而忙”，而是“忙得连午饭都忘了”。

**It was such a difficult question that nobody answered it.**

such 修饰名词短语 **a difficult question**，不是单独修饰 difficult。  
译：“这道题太难了，以至于没人回答。”

## 4. 比较结构也可以构成从属关系

**She works harder than I do.**

than 后面的 *I do* 用助动词 do 代替重复动词 works。不要读成两个互不相干的事件。译：“她工作比我更努力。”

**As he grew older, he became more patient.** 这里 as 表示随时间变化，不是简单比较：“随着年龄增长，他变得更有耐心。”

## 5. 遇到陌生连接词怎么办？

先判断它连接的两侧是否都是分句，再结合语义试验：

- 两个事实方向相反？可能是让步或转折。
- 后一事件是前一行动想实现的目标？可能是目的。
- 后一事件是程度引起的后果？可能是结果。
- 存在大小、程度比较？可能是比较。

这只是猜测路线，要以具体连接词用法核对。

## 6. 练习

A. Though the task was difficult, she finished it.  
B. He left early so that he could catch the train.  
C. The box was so heavy that I couldn't lift it.  
D. Even if you disagree, please listen.

<details><summary>答案</summary>

A 让步：“任务虽难，她还是完成了”。B 目的：“他早点走，好赶上火车”。C 程度结果：“箱子太重，我抬不动”。D 假设性让步：“即使你不同意，也请听一听”。C 中 couldn't 否定的是“能否搬起”，不可漏掉。

</details>

**过关线**：说明“为什么两段话放在一起”，并区分真实事实、假设与预期落差。
